### Данные (Dataset)
Исходные сырые данные не включены в репозиторий из-за ограничений GitHub на размер файлов 
### Где скачать данные
Полный набор данных доступен для загрузки на платформе Kaggle:
https://www.kaggle.com/datasets/cemeraan/fecom-inc-e-com-marketplace-orders-data-crm

###  Структура датасета

Архив содержит 8 CSV-файлов (разделитель `;`, кодировка `UTF-8`):

| Файл | Количество записей | Описание |
| :--- | :---: | :--- |
| `Orders.csv` | 99 441 | Информация о заказах, статусах и временных метках |
| `Order_Items.csv` | 112 650 | Позиции в заказах (SKU), цены и стоимость доставки |
| `Products.csv` | 32 951 | Каталог товаров, категории, габариты и вес |
| `Customers.csv` | 102 727 | Профили клиентов, демография и почтовые индексы |
| `Sellers_List.csv` | 3 095 | Информация о продавцах и их локациях |
| `Geolocations.csv` | 1 000 163 | Геокоординаты почтовых индексов |
| `Payments.csv` | 103 886 | Детали платежей по заказам (способ, рассрочка, сумма) |
| `Order_Reviews.csv` | 99 223 | Оценки (1-5) и текстовые отзывы клиентов |
