#  Анализ логистики и цепи поставок E-commerce Marketplace

##  О проекте

Комплексный аналитический проект по исследованию логистических процессов маркетплейса FeCom Inc. Анализ охватывает полный цикл от загрузки сырых данных до создания BI-витрин и проверки статистических гипотез.

**Цель:** Выявить узкие места в цепи поставок, оценить влияние логистических сбоев на удовлетворенность клиентов (CSAT) и оптимизировать финансовую эффективность доставки.

---

##  Ключевые бизнес-результаты

### Логистика и SLA
- **OTD Rate (On-Time Delivery):** 90.6%
- **Медианный Lead Time:** 10 дней (78% времени — транзит)
- **Доля кросс-бордерных доставок:** 63.8%
- **Критические маршруты:** Berlin → Montpellier (26.9% опозданий), Berlin → Athens (25.7%)

### Влияние на клиентский опыт (CSAT)
- Задержка доставки снижает медианную оценку с **5.0 до 1.0** (p-value < 0.0001)
- **53.7%** клиентов, получивших заказ с опозданием, ставят минимальную оценку
- Каждое опоздание стоит платформе ~4 балла рейтинга

### Финансовая эффективность
- **36.6%** заказов имеют долю логистики >30% от цены товара
- Категории с критической долей логистики: Drinks (93%), Home_Comfort_2 (93%)
- Физический вес сильнее связан со стоимостью доставки, чем объемный (ρ = 0.4511 vs 0.3695)

### Сегментация
- **RFM:** 40% клиентской базы в зоне оттока (At Risk + Hibernating), Champions — только 7%
- **ABC-XYZ:** 78% выручки генерируют 16 категорий группы A (правило Парето)

## ️ Ограничения анализа

1. **Наблюдательный характер данных:** Выявленные связи корреляционные, не причинные
2. **Отсутствие идентификатора перевозчика:** Невозможно сегментировать метрики по логистическим провайдерам
3. **Отсутствие COGS:** Метрика `freight_to_price_ratio` отражает долю в розничной цене, но не в марже
4. **Геодезическое расстояние:** Формула Haversine занижает реальные логистические плеча на 20-40%
